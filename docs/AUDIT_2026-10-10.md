## 安全与恢复边界

- 来源只读：扫描、预览、复制/校验仅以只读方式打开原片。配置无效时不得写来源；暂存/清理前验证目标路径边界。
- 回读校验：复制后 fsync、回读 BLAKE3；暂存摘要持久化；提交前重新核对；最终文件再次读取并校验。
- 不覆盖：目标已存在且内容相同则复用；不同内容则为 JPEG/RAW 配对统一添加后缀。执行过程中外部创建目标文件也不会被替换。
- 部分失败：已发布文件保持安全，暂存输入保留。重试识别相同内容/原冲突后缀；回执数据库事务失败时保留输入并明确提示重试。
- 会话保存：审片结果、已完成文件、待处理批次分开持久化。恢复先重新扫描来源，核对 Capture 身份，再重新校验未完成暂存；切换回来可恢复该来源的会话。
- 取消：复制和回读按块检查取消，未完成 `.part` 清理。最终提交属于不可中途关闭的短事务，完成后仍可继续审片。切换目标/格式会清理被替代的目标端暂存；切换来源保留其未完成会话。

## 验证命令

```sh
npm ci
npx playwright install chromium
npm run check
npm run test:ui
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets
npm run test:rust
```

UI 测试启动独立 Vite 服务并自动关闭，Tauri IPC 使用真实 Channel/Event 合约的可控模拟。Rust 回归直接操作临时目录，覆盖字节进度、复制/校验取消、并发目标创建、不覆盖、配对重名、部分提交重试、暂存损坏和 SQLite 批次事务。UI 覆盖连续/跨日期导入、恢复批次、目录/格式竞态、快速重新选择、确认取消与失败重试、自由比较、DPI、窗口 IPC、Modal 键盘及 reduced-motion。

本地平台为 Windows x64；TypeScript、UI、Rust、Clippy、格式和 Windows Release/NSIS/MSI 已检查。Windows 设备发现另执行只读实机 smoke test；相机/读卡器传输、拔卡、磁盘不足、FAT/exFAT、跨显示器 DPI 和标题栏原生拖动/缩放仍需要实机验收。macOS/Linux 构建交给新增 CI 矩阵；本机没有这些平台的交互环境。
